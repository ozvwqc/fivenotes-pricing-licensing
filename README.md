## 怎么选：三种人可以直接下单，两种人别买

FiveNotes 的产品逻辑很极端：只有五条笔记，官方说这是有意为之，逼你只留当下最要紧的信息。它常驻菜单栏，一个快捷键呼出，能浮在其他窗口甚至全屏应用之上，也能拖到屏幕边缘或跟着鼠标出现。Markdown、任务列表、搜索、主题字体、Apple Shortcuts、AppleScript 和 URL API 都有。

适合的人很具体。第一类是靠菜单栏速记的人，邮箱、电话、地址、临时想法，写完就关，不想打开一个庞大的笔记库。第二类已经有 Obsidian 或 Notion 这类主力库，缺一块“当前五件事”的浮层。第三类是 Mac 和 iPhone 都用，愿意为 iCloud 同步再付一次移动版的钱。

不适合的也明确。需要存长文、附件、多层文件夹和标签体系的人，五条上限会天天碍事，这不是设置里能改的。用 Windows 或安卓的人也不用考虑，FiveNotes 只做苹果平台。👉 [对照自己的用法看看 Mac 版授权是否够用](https://lizhi.shop/products/fivenotes?cid=7bbix2xj)

版本上我的建议是先只买 Mac 版。移动版 3.99 美元不贵，但它是配套角色，主力还是 Mac。手上没底就先下 30 天试用版，官网直接提供，试完再决定要不要掏钱。

学生可以留意开发商 FAQ 里提到的 Students App Centre，Mac 版在上面有学生折扣。这条是官方给的渠道，具体折多少我没核到，需要你到那边看。

## 几个容易被忽略的限制

五条笔记是硬上限，不是免费版限制，买断之后也还是五条。写满了要手动覆盖，用久了会形成一套自己的取舍习惯，不习惯的人第一周就会烦。

大版本升级另收费。买断只保当前大版本，FiveNotes 4 出来时不是免费升。6 个月内买过旧版的补救办法是联系开发商，属于人工处理，没有写进自动流程。

Mac 版和移动版分开销售。想手机上看笔记，只能再买一次，靠 iCloud 同步把内容串起来。这笔钱官方没有任何打包方案，别被“iCloud 同步”四个字误导成一次买全平台。

售后要分清对象。App 本身的问题找开发商，订单、发票、授权激活的问题找荔枝商店客服。荔枝的会员规则里写了订单退款后会从累计消费里扣回对应金额，但退款的具体条件我没查到明确条款，下单前问客服比事后扯皮省事。
